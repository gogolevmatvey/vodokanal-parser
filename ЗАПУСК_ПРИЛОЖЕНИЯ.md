## 🔧 Запуск Backend (Spring Boot)

### Шаг 1: Проверка PostgreSQL

Убедитесь, что PostgreSQL запущен и база данных существует:

```bash
psql -h localhost -p 5433 -U postgres -c "\l"
```

**Параметры подключения (из config.properties):**
- Host: `localhost`
- Port: `5433`
- Database: `vodokanal-db`
- Username: `postgres`
- Password: `postgres`

### Шаг 2: Компиляция Java (Maven)

**Важно!** Сначала нужно скомпилировать проект:

```bash
cd c:\GitHub Repositories\vodokanal-parser
mvn clean compile
```

**Ожидаемый вывод:**
```
[INFO] BUILD SUCCESS
```

**Или полная сборка:**
```bash
mvn clean package -DskipTests
```

### Шаг 3: Запуск через Maven

```bash
mvn spring-boot:run
```

**Или через IDE:**
- Откройте проект в IntelliJ IDEA / Eclipse
- Запустите класс `VodokanalApplication.java`

### Шаг 4: Проверка запуска

Дождитесь сообщения:
```
Started VodokanalApplication in X.XXX seconds
Tomcat started on port 8080 (http) with context path '/'
```

**Проверка API:**
```bash
curl http://localhost:8080/api/statistics
```

**Ожидаемый ответ:**
```json
{
  "success": true,
  "data": {
    "localities": 688,
    "streets": 4671,
    "houses": 85348,
    "apartments": 422571,
    "accounts": 433186,
    "billingPeriods": 433186
  }
}
```

## ✅ Проверка работы

### 1. Компиляция и запуск Backend

**В новом окне PowerShell:**
```powershell
cd "c:\GitHub Repositories\vodokanal-parser"
mvn clean compile spring-boot:run
```

Дождитесь:
```
Started VodokanalApplication in X.XXX seconds
Tomcat started on port 8080 (http)
```

### 2. Запуск Frontend

**В другом окне PowerShell:**
```powershell
cd "c:\GitHub Repositories\vodokanal-parser\src\main\resources\static"
ng serve --proxy-config proxy.conf.json
```

Дождитесь:
```
Application bundle generation complete. [X.XXX seconds]
Local:   http://localhost:4200/
```

### 3. Откройте браузер

Перейдите по адресу: **http://localhost:4200**

### 4. Навигация

В меню доступны разделы:
- **🔍 Поиск** — поиск по адресу (каскадные списки)
- **📥 Импорт** — загрузка данных (в разработке)
- **📊 Статистика** — статистика базы данных
- **🔑 Войти** — авторизация

### 5. Тестирование поиска

1. Откройте вкладку **"Поиск"**
2. Откройте **Developer Tools (F12) → Console** для просмотра логов
3. Начните вводить название населенного пункта (например, "Владимир")
4. Должны появиться подсказки из БД
5. Выберите улицу, дом, квартиру
6. Выберите лицевой счет

### 6. Проверка статистики

1. Откройте вкладку **"Статистика"**
2. Должны отобразиться данные:
   - Населенные пункты: 688
   - Улицы: 4671
   - Дома: 85348
   - Квартиры: 422571
   - Лицевые счета: 433186
   - Периоды: 433186

## 🔧 Решение проблем

### ❌ Ошибка: "Невозможно соединиться с localhost:8080"

**Причина:** Spring Boot не запущен

**Решение:**
```bash
cd c:\GitHub Repositories\vodokanal-parser
mvn spring-boot:run
```

---

### ❌ Ошибка: "Невозможно соединиться с localhost:4200"

**Причина:** Angular не запущен

**Решение:**
```bash
cd c:\GitHub Repositories\vodokanal-parser\src\main\resources\static
ng serve --proxy-config proxy.conf.json
```

---

### ❌ Ошибка: "PostgreSQL connection refused"

**Причина:** PostgreSQL не запущен или неверный порт

**Решение:**
1. Проверьте, что PostgreSQL запущен
2. Проверьте порт в `config.properties`:
   ```properties
   db.port=5433
   ```

---

### ❌ Ошибка компиляции Angular: "Cannot find module"

**Причина:** Не установлены зависимости Node.js

**Решение:**
```bash
cd c:\GitHub Repositories\vodokanal-parser\src\main\resources\static
npm install
```

---

### ❌ Ошибка: "Port 4200 is already in use"

**Причина:** Angular уже запущен

**Решение:**
```bash
# Windows
taskkill /F /IM node.exe

# Затем запустите снова
ng serve --proxy-config proxy.conf.json
```

---

### ❌ Ошибка: "Port 8080 is already in use"

**Причина:** Spring Boot уже запущен

**Решение:**
```bash
# Windows
taskkill /F /IM java.exe

# Затем запустите снова
mvn spring-boot:run
```
